# World map data

`world.json` holds the country and US-state outlines drawn by the world map view
of the server list. It is generated by `scripts/generate_world_map_data.py` from
the [Natural Earth](https://www.naturalearthdata.com) 1:110m datasets
(`admin_0_countries` and `admin_1_states_provinces`), which are in the public
domain.
